# 為文字，留一個位置。

Pageforge Native 使用 Flutter 畫面與 Go 本機服務。
來源、文字快照、筆記與進度都保存在自己的 library 資料夾。

## 開始閱讀

把 Markdown 或純文字放入 collection，再按「重新載入資料夾」。
也可直接用「匯入文件」選擇檔案；相同來源不會重複建立書籍。

文字可以選取、調整字級，或切到筆記記錄一個想法。
草稿自動暫存，正式保存會新增 VAX 版本。

## 試著修改

到「編輯」調整文字，按「保存為新版本」。
原始檔與既有版本保留。到「版本」比較修改內容；
還原會把舊內容保存成新版，不會抹除歷史。

目前是 Windows 第一階段，完整遷移進度請看專案 README 與 docs/MIGRATION.md。
這是一份隨專案保存的實際說明文件，可用來閱讀與試寫。
