# 視覺與互動設計

Pageforge 的方向是「獨立書店＋手稿工作室」。書架邀請使用者停留，閱讀區保留清楚的文字、選取與編輯能力。

## 本輪完成

- 書架包含品牌列、閱讀引導、資料夾同步、搜尋與文件卡片，資料都來自實際 library。
- 封面採 2:3 比例、書脊漸層、柔和陰影與五種向量線稿；文件 ID 決定色彩與樣式，重開維持一致。
- 襯線標題使用 Georgia，中文優先 Noto Serif TC，系統缺字體時回退 Microsoft JhengHei；不下載或散布系統字體。
- 文件卡片保留滑鼠、鍵盤焦點與按下回饋；遵守系統減少動畫設定。
- 較窄視窗會重排標題、匯入按鈕與搜尋，閱讀引導省略裝飾封面。
- 圖案以 CustomPainter 繪製，無網路圖片；獨立 RepaintBoundary 與 shouldRepaint 避免每幀重畫靜態線稿。

## 元件責任

LibraryScreen 負責頁面組裝與文件選擇。
LibraryHeader、ReadingInvitation、ShelfToolbar 分別管理品牌、閱讀引導和書架操作的版面。
BookTile 管理滑鼠與焦點回饋；BookCover、CoverArt 管理封面排版和靜態圖案。
資料、讀取和保存仍由 ViewModel／Repository／Go 分工。

## 接續雕琢

- 閱讀區的版面與頁邊筆記。
- 封面到閱讀頁的連續視覺轉場。
- 大字級、窄視窗與不同系統字體的更多實機驗收。

美術調整不得破壞跨段落選取、原始檔不可變、草稿保存與版本提交。


## 外觀工作室

色彩、標題字體、封面線稿、書架間距與文字閱讀行高可透過 JSON 外觀工作室調整。
預覽與正式元件共用，按「套用並保存」後才更新全域 Theme；見 [規格與後續階段](DESIGN_STUDIO.md)。
