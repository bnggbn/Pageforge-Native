# 段落筆記與線索牆

Evidence Wall 採「線索牆」作為介面名稱。每本書可建立多個主題畫布；筆記是線索來源，布局與紅線是整理思路的工作資料。

## 閱讀操作

選取 Markdown／TXT／EPUB 文字投影後，桌面右鍵或觸控長按選單選「作筆記」。保留原生複製及全選操作。作筆記的引用與段落範圍在下一個 Markdown 標題（h1–h6，含底線式標題）前停止；若從標題開始選取，仍可涵蓋該節正文。一般複製維持完整選取範圍，程式碼中的 # 不作為分節。筆記對話框保存精確引用、段落範圍與內容；引用超過設定上限時，先提示縮小選取，不污染草稿。

保存後，小雲緊跟段落最後一行的文字末端，按文字游標的終點水平位置與該行文字中心定位；點擊區為 48 × 48px，圖示為 32px。排版預留 56px 讓滿行的氣泡仍有空間，不遮住正文；調字級或視窗寬度後依重新排版的位置量測。正文從頂端開始，短文章不垂直置中。小雲顯示該段筆記數量。跨段筆記在範圍內各段顯示，同一筆記可同時出現在多個段落。點雲查看原始引用與筆記，並可新增該段筆記或在線索牆查看。小雲排除在文字選取容器外，不會混入複製內容。

既有未完成筆記會繼續原有草稿，不因選取另一段而被覆蓋。重開閱讀器可續寫筆記。保存筆記與刪除筆記仍提交 VAX 版本；切換頁籤及返回書架會等待草稿、閱讀進度、布局保存。

## 段落定位與舊資料

不增加 VAX Note 欄位。新筆記的既有 location 字串使用 pf:p1 格式，包含章節、原始章節內容 SHA-256、開始與結束段落 SHA-256，以及同文字段落的出現序號。段落雜湊使用渲染後文字並統一空白；內容與原始引用不被改寫。

文章內容未改變時用出現序號辨認重複段落。內容改變後，只在開始／結束段落各唯一且順序合理時重新定位；重複或找不到的段落不猜測綁定。既有筆記則用唯一引用文字比對，保持舊 location 與 VAX 節點不變。

EPUB 的新筆記先按章節索引隔離，再做段落比對。舊 Web 筆記的「章節標題 / block」可用唯一標題定位；無章節位置的舊筆記只在引用可唯一辨識章節時綁定。相同引用跨章節出現時不猜測，切換章節不重播前一次原文跳轉。

找不到原文的筆記仍在「全部筆記」及線索牆可查閱，回到原文時提示定位失敗。正文仍用共用 SelectionArea 和完整 Markdown 佈局，支援跨段落及包含畫面外文字的全文複製。大篇文章的分塊選取優化仍待實作。

## 線索牆操作

「全部線索」保留全部筆記及既有布局。新增命名主題時從空白畫布開始，使用「挑選線索」搜尋並勾選相關筆記；同一筆記可加入多個主題，每個主題的卡片位置與紅線獨立。可重新命名、切換或刪除命名主題；刪除主題及取消選擇不刪原筆記。從主題內新增筆記會直接加入該主題，其餘閱讀筆記先保留在「全部線索」。

目前主題以每本書為範圍，跨書籍線索仍待移植。選取的主題會隨布局保存，重開回到同一主題。

卡片標題與整片內容皆可拖曳（包含內容兩側空白）。按住時加深陰影、輕微放大並顯示抓握游標，放開或取消後恢復；點一下仍開啟筆記。圖釘與「回到原文」保留獨立手勢。降低動態效果時省略縮放與動畫，保留陰影與狀態提示。浮起僅影響呈現，不更改布局座標，也不在移動中寫入版本或磁碟。

拖曳調整位置時，直接由游標的畫布座標更新，卡片與紅線在本機即時跟隨，放開才更新持久布局，取消拖曳回到原位置。移動過程不通知整牆重建或發送布局寫入。拖曳圖釘到另一張卡片，或依序點兩個圖釘，建立紅線。點紅線可修改關係標籤或移除紅線。卡片可展開筆記或回到原文。畫布支援平移與縮放。

不允許自連線、重複無向連線或不存在的端點。刪除／還原筆記後，牆依目前版本重新整理卡片及連線。超過卡片上限的筆記仍可從「全部筆記」查閱。視窗外的卡片不建立 Widget；紅線集中繪製，點格背景只繪製視窗大小。

## 持久化合約

Go 的 GET／PUT /v1/books/{id}/evidence-wall 使用既有 loopback、Bearer token 與嚴格 JSON 驗證。檔案位於 library/books/{id}/evidence-wall.json，使用原子替換。

schemaVersion 為 2，revision 為布局寫入 token，updatedAt 為時間，activeTopic 為目前主題 ID，topics 每項含 id、name、cards、edges。cards 每項含 noteId、x、y；edges 每項含 id、from、to、label。全部主題在同一文件中原子保存，端點必須存在於紅線所屬主題。預設主題 ID 為 00000000-0000-4000-8000-000000000001，名稱固定「全部線索」，不能刪除或改名。PUT 包含 wall、expectedRevision 與 expectedHead。兩個基準均需符合，目前版本中的真實筆記才可成為端點。幾何、UUID、數量與標籤長度都由 Go 驗證；HTTP／檔案容量預設限制 4 MiB，可由 layoutMiB 設定。

舊 schema v1 在讀取時只於記憶體轉成「全部線索」，保留原 revision、卡片及紅線；首次成功保存 v2 前，會在同書資料夾保留原始位元組為 evidence-wall.v1.backup.json。備份不覆寫，保存或驗證失敗不切換布局；VAX、原檔及 manifest 不參與此轉換。舊後端不讀取 v2 布局；需要降版時先停止程序，再使用 v1 備份還原布局檔。

拖曳只防抖保存布局，不重新雜湊整條版本鏈。衝突或寫入失敗會保留本機布局並顯示錯誤，不覆蓋其他視窗更新；沒有自動合併或強制覆寫。筆記文本與引用繼續使用 VAX，布局與紅線目前不提供 VAX 歷史。

pageforge.config.json 的 evidenceWall 預設：

| 設定 | 預設 | 意義 |
| --- | --- | --- |
| maxTopics | 32 | 每本書的主題上限，含全部線索 |
| topicNameCharacters | 80 | 主題名稱字數上限 |
| layoutMiB | 4 | 整份布局與請求容量上限 |
| maxCards | 500 | 每個主題的卡片上限 |
| maxEdges | 1000 | 每個主題的紅線上限 |
| canvasWidth／canvasHeight | 6400／6400 | 畫布範圍 |
| saveDebounceMs | 500 | 布局保存防抖 |

舊設定未指定新欄位時使用相同預設。卡片尺寸 280 × 240 是目前介面幾何合約。

## 驗收與待補

自動測試涵蓋主題線索歸屬與布局隔離、舊布局唯讀轉換與精確備份、主題建立／搜尋／挑選、原始筆記保留、可配置段落間距與全文複製不變。另覆蓋 Windows 右鍵跨段筆記、標題前裁切且複製範圍不變、快速游標在 0.5／1／2 倍縮放下完整位移、小雲與全文複製、原文跳轉、Android 長按、引用超限保護、段落重新定位與歧義拒絕、滑鼠與觸控按住浮起／整片內容拖曳／取消復原／獨立按鈕手勢／降低動態效果、卡片拖曳／圖釘連線／視窗裁切、重開持久化、保存失敗與 CAS 衝突、VAX 不變性。

EPUB 此階段仍使用既有 library 的章節文字投影；新 EPUB 匯入、原版 XHTML 排版與 CFI 定位尚未移植。完整閱讀器可使用 [EPUB CFI](https://w3c.github.io/epub-specs/epub33/epubcfi/) 記錄來源書內位置，不能從純文字投影假造 CFI。

段落額外間距可在 JSON 外觀工作室的文字閱讀場景調整（reader.paragraphGapLines，0–3，預設 1），隨字級縮放，不改原文或 VAX；所有格式的文字選取仍共用一個選取範圍。

Windows 是目前建置平台；手機平台啟動與 Go 儲存橋接尚未完成。PDF／XLSX 精確段落定位、跨書籍線索、人工重綁、布局 VAX 歷史與衝突合併待補。Windows 強制終止／關閉前最後一次防抖保存仍可能尚未落盤，關閉攔截需另外完成。
